# Script 2 · Les théories sociologiques des professions (2:24, 9:16 + 16:9)

The film is built around one object: **the lock on a profession's door**. Its pins are the *criteria*
for getting in. Each of the three theories reads the same pins differently. The pins move
like the pins in a real pin-tumbler lock: a key rides its teeth under them, and the door opens
only when every pin sits on the shear line.
