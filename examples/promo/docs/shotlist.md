# AI Motion Studio: promo, shot list

**Logline:** anyone can make aesthetic, motion-driven video now: one prompt in, a rendered film out.
**Duration / BPM / formats:** 17 s · 120 BPM (1 beat = 0.5 s) · 9:16, 16:9
**Music:** synthesized `pulse` in A minor, drums out for bar 6, final hit on beat 28
**Real material only:** the code on screen is the studio's own API (`spring`, `track`, `S.beat`); the filmstrip
and review grid are real frames from `examples/showreel` and `examples/yourbrand`; the palette and mark are the repo's.
